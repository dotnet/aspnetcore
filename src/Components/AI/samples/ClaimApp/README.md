# Components.AI claim sample

This Interactive Server sample exercises the Components.AI claim POC, including streamed text, backend tools, frontend actions, synchronized state, approvals, rejection reasons, cancellation, and user-safe errors.

From the repository root:

```bash
source activate.sh
dotnet run --project src/Components/AI/samples/ClaimApp/ClaimApp.csproj --no-restore
```

The sample opens at `http://127.0.0.1:5099`.
